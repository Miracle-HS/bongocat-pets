# BongoCat 点击数工具

给 Steam 桌面宠物 [BongoCat](https://store.steampowered.com/app/3419430/Bongo_Cat/) 的单机辅助脚本：修改点击数、加速宝箱冷却、自动开箱。数据走 Steam 本地统计，改动安全。

当前版本 **v1.1.0**，适配游戏 **2026-09 / 2026-10** 两代。界面顶部显示工具版本与适配代次，「自动开箱」区里的「游戏版本」显示实际检测到的 Steam build 与更新时间。

## 下载与快速开始

1. 在 Windows 上下载 [v1.1.0 发布页](https://github.com/Miracle-HS/bongocat-pets/releases/tag/v1.1.0) 中的 [BongoCat.exe](https://github.com/Miracle-HS/bongocat-pets/releases/download/v1.1.0/BongoCat.exe)，无需安装 Python。
2. 启动 BongoCat 游戏，再运行工具；工具会自动连接进程并扫描定位。
3. 定位成功后，在「② 操作面板」修改点击数或宝箱冷却；需要自动开箱时点击「打补丁」。

> **打补丁或还原会重启正在运行的游戏**：工具先关闭游戏、写入 DLL，再启动游戏并自动重连。游戏原本未运行时不会自动启动，请自行启动后连接。
> 同一 Windows 会话内只允许打开一个新版工具窗口，重复启动会尝试唤回已有窗口，最小化时会恢复。旧版 EXE 不包含单实例保护，升级前请先关闭旧版。

## 从源码运行

需要 Windows + Python ≥ 3.10（tkinter 随安装包自带，无需另装）。下载或克隆仓库后，在项目根目录执行：

```bash
python gui.py
```

基础内存读写与界面仅使用 Python 标准库；使用自动开箱的「打补丁」「还原」按钮或 `patch_dll.py` 时，还需要安装 DLL 解析库：

```bash
python -m pip install dnfile
```

EXE 已包含所需依赖，无需执行上述安装命令。

## v1.1.0 更新

- **单实例窗口**：避免重复打开工具，重复启动时尝试恢复并置前已有窗口。
- **界面优化**：输入框与按钮保持相邻，长按钮单独成行；支持鼠标滚轮滚动，并根据内容和屏幕高度调整初始窗口大小。
- **补丁自动重启**：打补丁或还原时处理 DLL 占用和残留进程，完成后自动启动并重连正在运行的游戏。
- **取消重连前的 90 秒窗口等待**：检测到游戏进程即开始重连，不再等待可见窗口；扫描及游戏数据就绪仍需要时间。
- **自动定位重试**：扫描未命中且检测到游戏窗口时进行有限次数重试。

## 主程序：`python gui.py`

BongoCat 游戏开着就行。工具启动后自动连接进程并做只读扫描，定位点击数与宝箱对象；扫描耗时取决于机器和游戏状态，未命中且检测到游戏窗口时最多自动重试 5 次。三个功能都在「② 操作面板」卡片里：

| 功能 | 操作 | 效果 |
|---|---|---|
| 改点击数 | 「一键清零」/ 输入累计花费 + 「应用」 | 把花掉的点击数拿回来（上限 = 累计获得） |
| 改点击数 | 勾选「锁定累计花费」 | 之后开箱不再扣点，扣除被工具即时拦回 |
| 宝箱冷却 | 「冷却上限(秒)」+「应用」/「立刻上架」 | 30 分钟可缩到几秒；倒计时压到 1 秒 |
| 宝箱冷却 | 勾选「保持随时可开」 | 倒计时一超过设定上限就自动压回去 |
| 自动开箱 | 「打补丁」按钮 | 自动备份原 DLL；游戏运行时先关闭游戏，写入后自动启动、重连并定位 |
| 自动开箱 | 勾选「暂停自动开箱」 | 工具按住倒计时不让归零，临时关闭自动买，不碰文件 |
| 自动开箱 | 「还原」按钮 | 用备份恢复原版 DLL；游戏运行时同样自动重启并重连 |

> 自动开箱的原理：把游戏 `Assembly-CSharp.dll` 里 `Shop.OnChestReady()` 尾部的"显示宝箱图标等你点"（10 月起为 `_shopVisuals.Show()`）等长替换为 `_shopItem.Buy()`，宝箱一就绪游戏自己就买。前提：游戏内「宝箱弹窗」设置保持开启。
> 点数值 60 秒内由游戏的 `StoreStats()` 写回 Steam，重启不丢；界面显示拍一下猫键盘即刷新。

## 命令行用法（不开 GUI）

命令行补丁操作不会自动重启游戏。执行 `--apply` 或 `--restore` 前先关闭 BongoCat，完成后自行启动；也可以加 `--wait` 等待游戏退出。

```bash
python patch_dll.py --status         # 查看 DLL 状态、补丁代次与游戏版本
python patch_dll.py --apply          # 打补丁并自动备份（先关闭游戏）
python patch_dll.py --apply --wait   # 等待游戏关闭后打补丁
python patch_dll.py --restore        # 按最近备份还原（先关闭游戏）
python pets_tool.py auto             # 只读定位点击数，打印地址和数值
```

从定位结果复制地址，替换下列命令的 `<addr>`，不要保留尖括号：

```text
python pets_tool.py spent <addr> 0   # 累计花费清零
python pets_tool.py hold <addr>      # 持续锁定当前累计花费，Ctrl+C 停止
python pets_tool.py hold <addr> 0    # 持续锁定累计花费为 0
```

## 文件结构

| 文件 | 职责 |
|---|---|
| `gui.py` | 主程序（tkinter 深色界面）：连接 → 定位 → 改数值 / 冷却 / 打补丁 |
| `gamemem.py` | 底层库：ctypes 内存扫描、读写、进程查找（无第三方依赖） |
| `gameinfo.py` | 游戏目录定位（Steam 注册表 / 库清单 / 运行中进程）+ 游戏版本号读取 |
| `autoclick.py` | DPI 感知点击探测 + `config.json` 读写（开箱计数、游戏目录存这里） |
| `patch_dll.py` | 等长 IL 补丁器：双代模式自适应，匹配不唯一就拒写 |
| `pets_tool.py` | 点击数定位/修改的命令行版（与 GUI 卡片①同源） |
| `version.py` | 工具版本号与适配的游戏代次 |
| `assets/` | 图标与本文档流程图 |

> 游戏 DLL 路径不写死：工具按 Steam 注册表、库清单（`libraryfolders.vdf`）、运行中的游戏进程、常见安装路径依次查找；都没命中时可在界面点「选择游戏目录」手动指定（选含 `BongoCat.exe` 的那层），路径会记进 `config.json` 下次直接用。也可设环境变量 `BONGOCAT_DIR` 指向游戏根目录。
> 当前游戏 2026-10 代：`Shop`/`Pets` 字段布局与内存定位逻辑全部通用；补丁点由 `patch_dll.py` 动态解析 token 适配。

## 问题排查

- **数字不刷新 / 显示“—”**：若游戏刚重启或手动重启过，先点「连接进程」，再点「自动定位」重扫；游戏累计点击数不足 5000 时也可能无法定位。
- **补丁后正在重连或自动定位**：v1.1.0 已取消重连前的 90 秒窗口等待，但内存扫描和游戏加载仍需时间；未命中且检测到游戏窗口时会有限重试。若提示窗口不存在，请确认游戏已启动，再重新连接、定位。
- **重复启动没有新窗口**：这是单实例保护，先检查原窗口或任务栏；关闭原实例后才能重新打开。
- **补丁状态显示“原版”、自动开箱突然不干活**：Steam 更新可能覆盖了 DLL，在 GUI 点「打补丁」重新应用；使用命令行 `--apply` 时先关闭游戏。
- **`--apply` 报"找不到原版字节"**：游戏代码又改版了，补丁脚本按设计拒绝写入（不会写坏文件），需要重新做一轮 IL 差分维护。
- **显示"未找到游戏"**：自动查找全部落空（非 Steam 安装、Steam 装在非常规位置、游戏没运行等）。点「选择游戏目录」手动指定，或设环境变量 `BONGOCAT_DIR` 指向游戏根目录。`python patch_dll.py --status` 会打印它尝试过的所有路径，便于排查。
- **「游戏版本」栏只显示代次、没有 build 号**：说明游戏不是通过 Steam 安装的，工具读不到 Steam 清单，属于正常降级。
- **提示权限不足**：游戏装在 `Program Files (x86)`，个别环境需要以管理员身份运行终端再执行写补丁命令。
