# BongoCat 点击数工具 · 使用说明

给 Steam 桌面宠物 [BongoCat](https://store.steampowered.com/app/1737300/BongoCat/) 的单机辅助工具：修改点击数、加速宝箱冷却、自动开箱。游戏无联网对战与反作弊，数据走 Steam 本地统计，改动安全。

## 快速开始

双击 **`BongoCat点击数工具.exe`**（BongoCat 游戏开着即可）：

1. 工具自动连接游戏并扫描内存，约 10 秒
2. 「① 连接 · 定位 · 数值」卡片出现累计获得 / 累计花费 / 可用点击数，即定位成功
3. 到「② 操作面板」里选功能使用；所有改动即时生效，无需重启

> 窗口标题栏状态为红色「未连接」时：先启动 BongoCat，再点「重新连接」。

## 三个功能

### 改点击数（屏幕上的"可用点数"）

| 操作 | 效果 |
|---|---|
| 「一键清零」 | 把累计花费归零，立刻拿回全部点击数 |
| 输入数值 + 「应用」 | 自定义累计花费（0 ~ 累计获得之间） |
| 勾选「锁定累计花费」 | 开箱不再扣点，每次扣除被工具拦回 |

拍一下猫键盘即可刷新游戏内显示；60 秒内自动写回 Steam，重启不丢。

### 宝箱冷却

| 操作 | 效果 |
|---|---|
| 「冷却上限(秒)」+「应用」 | 把 30 分钟缩短成比如 5 秒一对（普通/表情两个宝箱同时改） |
| 「立刻上架」 | 把倒计时压到 1 秒 |
| 勾选「保持随时可开」 | 倒计时一超过设定上限就自动压回去 |

### 自动开箱（DLL 补丁，推荐）

给游戏 `Assembly-CSharp.dll` 打一个 12 字节等长补丁：宝箱就绪时游戏自己购买，全程零点击、与鼠标坐标无关。

1. 点工具里的「打补丁」（或双击 `打补丁-自动开箱.bat`）——游戏开着也能直接写，工具会自动备份原 DLL
2. **重启 BongoCat** 补丁生效；之后每次重置的宝箱都会自动开
3. 临时关掉：勾选「暂停自动开箱」（工具按住倒计时不让归零，不碰文件）
4. 彻底还原：点「还原」按钮，或双击 `还原原版DLL.bat`（用最近一次备份）

前提：游戏内「宝箱弹窗」设置保持**开启**，关了补丁不会触发。

## 文件清单

| 文件 | 用途 |
|---|---|
| `BongoCat点击数工具.exe` | 主工具（绿色单文件，含以上全部功能） |
| `启动GUI.bat` / `启动GUI-调试.bat` | Python 源码方式启动（调试版带控制台） |
| `打补丁-自动开箱.bat` / `还原原版DLL.bat` | 命令行打补丁 / 还原 |
| `打包exe.bat` | 改过 .py 源码后重新打包 exe 用（需要电脑装有 Python） |
| `gui.py` `patch_dll.py` `gamemem.py` `autoclick.py` `pets_tool.py` | 源码 |
| `config.json` | 开箱计数记录，可删可改 |

## 问题排查

- **Steam 更新后自动开箱失效**：官方会覆盖 DLL。重启游戏后用工具重新点一次「打补丁」即可；若提示找不到补丁位置，说明游戏代码又改了，重新维护（见下条）。
- **命令行诊断**：在项目目录开个终端跑 `python patch_dll.py --status`，能看到当前 DLL 是原版/已打补丁、以及识别的具体代次。
- **数值卡片显示"?"或数字不动**：基址失效（多半刚重启过游戏），点「自动定位」重扫。
- **EXE 被 Windows 提示拦截**：SmartScreen 弹窗点「仍要运行」（PyInstaller 打包的常见误报）。
